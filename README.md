# Vehicle Service Center Management System

## Project Description

This is a MySQL database project for managing a Vehicle Service Center.

The project manages customer details, vehicle information, mechanic details, service records, and billing information.

## Database Tables

1. Customers
2. Vehicles
3. Mechanics
4. Service_Records
5. Bills

## SQL Concepts Used

- Primary Key
- Foreign Key
- INNER JOIN
- WHERE
- GROUP BY
- HAVING
- COUNT()
- SUM()
- AVG()
- MAX()
- ORDER BY
- LIMIT
- Subqueries
- Date Functions
- RANK()

## Tools Used

- MySQL
- MySQL Workbench

## Project Queries

The project contains 20 SQL queries covering vehicle services, mechanics, customer bills, payments, service history, revenue, and ranking.
